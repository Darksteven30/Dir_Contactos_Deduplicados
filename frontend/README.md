# Frontend: Directorio de Contactos

SPA en **Vue 3 + TypeScript + Pinia + Vue Router**, con estilos de **Tailwind CSS** y **Axios** como cliente HTTP.

La guía de instalación, los comandos y la arquitectura del frontend están en el [README principal](../README.md#3-frontend).

```bash
npm install
npm run dev        # http://localhost:5173 (requiere el backend en localhost:3000)
npm run test:unit
```

Editor recomendado: VS Code con la extensión [Vue (Official)](https://marketplace.visualstudio.com/items?itemName=Vue.volar).
